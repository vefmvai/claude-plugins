# Плагины Claude Code от vefmvai

Каталог. Сами плагины живут в своих репозиториях — здесь только список.

## Как подключить

```
/plugin marketplace add vefmvai/claude-plugins
```

Это делается **один раз**. Дальше ставится любой плагин из списка:

```
/plugin install loreground@vefmvai
```

Обновить список: `/plugin marketplace update vefmvai`.

## Что есть

| Плагин | О чём | Репозиторий |
|---|---|---|
